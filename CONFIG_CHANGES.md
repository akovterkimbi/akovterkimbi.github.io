# _config.yml — values to change

Open `_config.yml` in the repo root and update these fields (leave everything else as-is):

```yaml
title: "Emmanuel Terkimbi Akov"
name: "Emmanuel Terkimbi Akov"
description: "Lecturer I, Department of Political Science, University of Uyo, Nigeria"

url: "https://akovterkimbi.github.io"
baseurl: ""

author:
  name: "Emmanuel Terkimbi Akov"
  avatar: "profile.png"   # replace images/profile.png with his photo, keep this filename
  bio: "Lecturer I, Political Science, University of Uyo"
  location: "Uyo, Akwa Ibom State, Nigeria"
  employer: "University of Uyo"
  email: "akovterkimbi@uniuyo.edu.ng"
  googlescholar: ""   # paste his Google Scholar profile URL here if he has one
  orcid: ""            # paste his ORCID iD here if he has one
  researchgate: ""     # paste his ResearchGate username here if he has one
```

Notes:
- Leave `googlescholar`, `orcid`, `researchgate` blank (or remove those lines) if he doesn't have those profiles yet — an empty value just hides the icon on the site.
- The exact key names can vary slightly by template version — if you don't see one of these fields, search the file for "author:" and add the missing lines under it, matching the indentation of the lines around it.
